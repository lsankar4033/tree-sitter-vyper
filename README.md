# tree-sitter-json

Vyper grammar for [tree-sitter][].

[tree-sitter]: https://github.com/tree-sitter/tree-sitter

`grammar.js` is forked from [tree-sitter-python](https://github.com/tree-sitter/tree-sitter-python), so there's likely still some python cruft here. 

Contributions to clean them up are welcome!
